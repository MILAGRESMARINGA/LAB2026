# LAB — Novo aplicativo

Aplicação isolada do CRMIMOBI, em construção na branch `lab-rebuild-2026`.

## Rodar localmente
```bash
cd lab-app
npm install
npm run dev
npm test
npm run build
```

A versão inicial implementa cânon, calendário anual completo e marcações apenas em memória. Autenticação, persistência, grupos e gamificação são etapas seguintes. Nenhuma migração de banco de dados foi aplicada.
